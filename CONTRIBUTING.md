# Contributing

Bug reports, device and compatibility reports, and feature requests are welcome and need no agreement.

## Code and documentation contributions

Every commit in a pull request must be signed off under the [Developer Certificate of Origin 1.1](https://developercertificate.org/), for example with `git commit -s`, which adds a line like:

    Signed-off-by: Your Name <your.email@example.com>

By submitting a contribution with that sign-off you also agree to this grant: you license your contribution to the project owner (Kiloton Labs) under the project's license, and additionally grant the project owner a perpetual, worldwide, non-exclusive, royalty-free, irrevocable license to use, modify, sublicense and relicense your contribution under any other terms, including commercial licenses. You keep the copyright in your contribution.

If you do not wish to give this grant, say so in the pull request. Your code will not be merged, but your report, test case or idea is still welcome.
